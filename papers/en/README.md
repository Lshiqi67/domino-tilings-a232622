## 构建与核对

在本目录运行 `./build.ps1`。需要 Python、SymPy 和 pdfLaTeX，以及现有 LaTeX 包。先运行精确公式转录检查，再编译两遍并拒绝溢出、缺字与未定义引用。

在仓库根目录运行 `python -X utf8 review/m1-m6/check_delivery.py` 可核对新版引用、归档摘要、源码记录和 PDF 摘要；这不执行 Lean，也不替代视觉检查。
