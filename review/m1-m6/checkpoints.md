# 依赖、实现差异与语义审阅重点

## 从对象到主定理

```text
M1 无序格对、精确覆盖、末列洞与零宽守卫
 ├─ 实际坐标作用 → 固定集与商集基数
 └─ M2 Bonds → Grid → Frame → StatePath 的互逆构造
       ├─ 末步不交分拆 → 实际 profileCount 递推
       └─ M3 坐标与路径相容 → 中线限制/补全 → 实际固定数
             ↓
M4 支持与计数的同步归纳 → α/β 接回真实基数 → 固定数奇偶式
M5 对 M1 的实际群作用用 Burnside → 4a=d+h+v+r
             ↓
M6 真实基数系数级数 → 四固定级数恒等式 → BA=N → 单位逆
             ↓
取所有 n+7 次系数及 0..6 次系数 → 七阶递推与全部初值
```

这里只表示逻辑阅读顺序，精确项目导入闭包由脚本记录。代数文件 `ThreeRows/Algebra.lean` 没有导入计数模块。基本块、M7–M11 和任何有限枚举输出都不是这条主式证明的前提。

## 最容易误判的接口

| 问题 | 本轮源码核对所得判断 | 外部应检查的内容 |
| --- | --- | --- |
| 无序砖是否仍有隐藏标签？ | `Edge` 是 Finset 的子类型；存在端点只出现在性质中，集合交换不变 | 砖的相等、铺法集合和中间 Bonds 表示是否保持正确等价 |
| 零宽的 S 是否任意？ | 不是；`PartialTiling` 有 `w=0 → S=∅` 守卫 | 若去掉守卫，洞集恒空会产生不应出现的终端；核查路径端也对应 |
| 补全是否只是选择了某个等势映射？ | 先构造路径折回，再用几何等价还原；Geometry 证明内部和跨线实际砖对应 | 同时读两个逆等式与 S13 的几何定理；类型等价本身不保证“限制”一词的几何含义 |
| rho 固定是否要求左半也有 h 对称？ | 不要求；只限制 J(S)=S | 定义域不能变小，否则漏计 |
| α、β 的递推为什么能数铺法？ | 先递归定义，后由 `profile_even_odd` 归纳接回 `profileCount` | 要读桥接证明，不能只看 `alpha_succ`、`beta_succ` 的 rfl |
| 一般高度是否都已通过？ | 本包只含三行局部规则与 h 特例；Burnside 自身有一般参数 | 论文一般 m 的引理不整体盖章；不要混用 M8 的证据 |
| 除以 4 是否偷偷截断？ | 先证乘法等式和整除，后得自然数/有理数平均 | 确认分子正负项和类型转换顺序 |
| 幂级数能否随便除以 x？ | x 不是单位；这里是系数移位 | `even_shift_identity` 与分母常数项为 1 的单位逆需区分 |
| 七阶递推的起点？ | 对所有 n∈ℕ 的 n+7 位置；初值从同一系数恒等式导出 | 等价于正文 n≥7；不是给定初值后另定义一个序列 |
| “完整矩形对称”是否由 Lean 分类？ | 没有；代码给出四坐标作用及其轨道关系 | 人工核对非正方形的欧氏解释，零宽按明示约定处理 |

## 建议审阅程序

第一遍不运行程序，读主定理类型并逐个展开 `a → orbitCount → TilingOrbit → Tiling`，确认量词、集合和等价关系。第二遍读 S05–S16 的双射、边界和归纳，尝试指出可能错位的格对/状态。第三遍读计数桥接及系数论证，再运行探针核对当前源码版本。

发现异议时提供：S 编号、论文位置、Lean 声明及参数、问题性质、反例或待证明步骤。区分“代码不表达论文”“该定理只覆盖特例”“证明未通过”“表述不易理解”。未审项目保持待审，不要求一次看完全部 413 声明。

## 信任和证据

历史 M6 报告记录 413 项声明及传递公理依赖，允许 `propext`、`Classical.choice`、`Quot.sound`。本轮探针重新输出这些公理依赖，不是重新实现 Lean 内核。标准 `decide` 的有限判定与新引入外部公理是两种情形。依赖编译缓存、工具链实现和数学语义仍有不同信任层；内核通过不回答文献优先权。

本轮没有指出 M1–M6 的具体语义反例；这只是准备者在所列接口上的核对结论，不是全代码外部认证。
