## 固定目标

对全部 n≥0，a(n) 是无标号多米诺铺满 3×2n 矩形后，在恒等、上下反射、左右反射及半周旋转组成的四元群下的轨道数。无 tatami 限制；空棋盘计一次；x 记录半宽。主式为

$$A(x)=\frac{1-3x-4x^2+10x^3-4x^5+x^6}{(1-x)(1-4x+x^2)(1-4x^2+x^4)}.$$

还包括全部指标七阶递推和初值 1,2,5,14,46,156,561。递推在整数域解释；a(7)=2037 是起点检查。审阅不包含最小阶数声明。

## 复现

在仓库根目录运行（Python 标准库即可）：

```powershell
python -X utf8 review/m1-m6/check_pack.py
python -X utf8 review/m1-m6/check_pack.py --lean --output review/m1-m6/checks/local-rerun
```

默认命令只检查摘要、映射、声明位置及项目导入闭包，不启动 Lean；`--lean` 先构建固定模块，再编译 Probe 和全部 413 项公理探针，记录真实退出码。输出目录必须不存在。前提是已安装固定工具链和项目依赖；首次依赖安装可能需要联网。脚本不自动运行更晚阶段、历史枚举或外部审阅。

历史完整 M6 验收命令在 [M6 说明](../../lean/docs/m6-main-theorem.md)。若使用该旧阶段脚本，应从本包记录的基线提交建立独立检出，避免其总入口随着以后阶段变化。
