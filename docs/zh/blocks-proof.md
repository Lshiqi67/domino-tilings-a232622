## 1. 命题、对象与约定

对 $n\ge1$，令 $\mathcal T_n$ 为用无标号 $1\times2$ 多米诺铺满三行、$2n$ 列单位格矩形的所有铺法，允许砖旋转，不留空、不重叠，不施加 tatami 限制。一个铺法是相邻格无序对的集合，交换砖的名字或一块砖两端的顺序不产生新铺法。

行号 $r=1,2,3$ 从上到下，列号 $c=1,\ldots,2n$ 从左到右。记

$$h(r,c)=(4-r,c),\qquad v(r,c)=(r,2n+1-c),\qquad \rho=hv.$$

群 $G=\{e,h,v,\rho\}\cong C_2\times C_2$ 作用在铺法上。因为 $2n\ne3$，这是保持该非正方形棋盘的完整平面等距对称群；四分之一周旋转不属于其中。令 $a(n)=|\mathcal T_n/G|$。$n=0$ 时定义 $\mathcal T_0$ 只含空铺法，四个抽象群元素均固定它，故 $a(0)=1$。

要证明 [题面](statement.md) 中的生成函数：

$$\boxed{A(x):=\sum_{n\ge0}a(n)x^n=\frac{-1+3x+4x^2-10x^3+4x^5-x^6}{(x-1)(x^2-4x+1)(x^4-4x^2+1)}.}$$

所有生成函数在 $\mathbb Q[[x]]$ 中运算。$x$ 的次数始终记录棋盘半长度；不涉及解析收敛、极限交换或砖数变量。

## 2. 切口状态与局部完备性（L001）

对任意三行铺法，在第 $j$ 列和第 $j+1$ 列之间定义切口状态 $S_j\subseteq\{1,2,3\}$：$r\in S_j$ 当且仅当有水平砖连接 $(r,j)$ 与 $(r,j+1)$。两端设 $S_0=S_w=\varnothing$，其中 $w$ 是列数。

设某列左侧状态为 $p$，右侧状态为 $q$。这一列中：$p$ 中的格已由左来的砖覆盖，$q$ 中的格由向右的砖覆盖，剩余格必须在本列用竖直砖覆盖。因此转移合法当且仅当

$$p\cap q=\varnothing,\qquad \{1,2,3\}\setminus(p\cup q)\text{ 能按相邻行分成二元组}.$$

高度为 3 时，剩余格只能为空、$\{1,2\}$ 或 $\{2,3\}$；每种情形的竖直砖放法唯一。穷尽八种输入得到表：

| 输入 $p$ | 全部合法输出 $q$ |
| --- | --- |
| $\varnothing$ | $\{1\},\{3\},\{1,2,3\}$ |
| $\{1\}$ | $\varnothing,\{2,3\}$ |
| $\{2\}$ | $\{1,3\}$ |
| $\{3\}$ | $\varnothing,\{1,2\}$ |
| $\{1,2\}$ | $\{3\}$ |
| $\{1,3\}$ | $\{2\}$ |
| $\{2,3\}$ | $\{1\}$ |
| $\{1,2,3\}$ | $\varnothing$ |

这张表不仅给出必要条件。反过来，任意长 $w$、从空状态回到空状态的合法路径都唯一确定铺法：在每个 $S_j$ 指定的行放跨切口水平砖，在每列剩下的相邻行放唯一的竖直砖。输入输出不交保证同格不被两个水平砖使用，剩余格规则保证恰好覆盖一列；端点空状态保证砖不越过棋盘。因此这是完整双射。

该表也说明从空状态不可到达 $\{2\},\{1,3\}$，但完备性证明仍列出了这两个候选状态，没有在论证前假定它们无关。

## 3. 不可竖切基本块的完整分类（L002）

称内部切口 $j$ 为**断口**，若 $S_j=\varnothing$。称非空铺法为**基本块**，若没有内部断口。它对应上节状态图从空状态出发、首次回到空状态的一段路径。

从空状态只能有三种第一步。

**情形 C：**第一步到 $\{1,2,3\}$。下一步只能回到空状态，所以列数恰为 2，三行各有一块水平砖。记此基本块为 $C$。

**情形 A：**第一步到 $\{3\}$。从 $\{3\}$ 可以回空状态，或者到 $\{1,2\}$；从 $\{1,2\}$ 只能回 $\{3\}$。在首次回空状态之前，路径必须且只能为

$$\varnothing\to\{3\}\to\bigl(\{1,2\}\to\{3\}\bigr)^{k-1}\to\varnothing,\qquad k\ge1.$$

这里括号表示重复的两步，$k=1$ 时不重复。总步数为 $2k$。记这块为 $A_k$，其坐标描述为：

- 第 1、$2k$ 列各有一块覆盖第 1、2 行的竖直砖；
- 第 3 行的水平砖连接列 $(2j-1,2j)$，$j=1,\ldots,k$；
- 第 1、2 行各自的水平砖连接列 $(2j,2j+1)$，$j=1,\ldots,k-1$。

**情形 B：**第一步到 $\{1\}$。由完整转移表，其后只能在 $\{1\},\{2,3\}$ 之间交替，最后由 $\{1\}$ 回空状态。得到且只得到 $B_k=h(A_k)$，$k\ge1$：两端的竖直砖覆盖第 2、3 行，第 1 行用奇偶列对水平铺满，第 2、3 行内部用偶奇列对水平铺满。

三种第一步穷尽所有可能，每一分支又穷尽所有首次回返路径，因此全部基本块恰为

$$\boxed{\mathcal B=\{C\}\cup\{A_k,B_k:k\ge1\}.}$$

上述坐标也直接验证它们都是合法基本块：$A_k$ 的奇数内部切口由第 3 行水平砖跨越，偶数内部切口由第 1、2 行水平砖跨越，所以不存在断口；$B_k$ 经行反射同样成立；$C$ 的唯一内部切口有三块水平砖跨越。$A_k$ 和 $B_k$ 的首列竖直砖位置不同，二者不同；$C$ 不含竖直砖，因此与二者也不同。没有重计。

图只展示 $C,A_1,B_1,A_2,B_2,A_3,B_3$；一般分类的依据是完整状态论证，不是图形外推。

## 4. 唯一分解与长度权重（L003）

对任意完整铺法，把它的全部内部断口按列号排序并切开，所得每段都没有内部断口，故都是上节基本块。这是唯一分解：任何拼接分界都必须是断口，而遗漏某个断口会使包含它的块不再基本。

反向将任意有限基本块序列首尾相接得到一个合法完整铺法，拼接线都是断口，块内没有断口，所以再分解恰好恢复原序列。空序列对应空铺法。由此得到铺法与基本块字的保权双射。

给 $C$ 权重 $x$，给 $A_k,B_k$ 权重 $x^k$。拼接的权重相乘。每个系数只涉及有限多个字，因此可以作形式幂级数求和。基本块生成函数与普通铺法生成函数分别为

$$F(x)=x+2\sum_{k\ge1}x^k=\frac{3x-x^2}{1-x},$$

$$D(x)=\sum_{\ell\ge0}F(x)^\ell=\frac1{1-F(x)}=\frac{1-x}{1-4x+x^2}.$$

这里重新证明了此前从 Mathar 文献引用的普通铺法公式；本证明不需要将该公式当作前提。

## 5. 三种对称在基本块字上的作用（L004）

定义保权字母对合 $\sigma(C)=C$、$\sigma(A_k)=B_k$、$\sigma(B_k)=A_k$。由坐标定义，上下反射正是 $\sigma$。

每个基本块都左右对称。对 $A_k$，列反射 $c\mapsto2k+1-c$ 交换两端的竖直砖；把第 3 行的列对 $(2j-1,2j)$ 映到另一奇偶列对，对应 $j\mapsto k+1-j$；把第 1、2 行的列对 $(2j,2j+1)$ 映到另一偶奇列对，对应 $j\mapsto k-j$。这些砖集合分别保持不变。$B_k$ 的结论由上下、左右反射交换及 $B_k=h(A_k)$ 得出。$C$ 的三块水平砖逐块保持不变。

全棋盘反射保持“无砖跨越”这一性质，故将断口集合映到断口集合。上下反射保持块次序，左右反射颠倒块次序。由唯一分解，对字 $W=b_1\cdots b_\ell$，三种作用精确为

$$h(W)=\sigma(b_1)\cdots\sigma(b_\ell),\quad v(W)=b_\ell\cdots b_1,\quad \rho(W)=\sigma(b_\ell)\cdots\sigma(b_1).$$

这一论证适用于块长度不同的序列，因为断口也被反射，比较的是唯一分解后的整个字，并未假定所有块等宽。

## 6. 固定点生成函数（L005）

记 $D,H,V,R$ 分别为 $e,h,v,\rho$ 的固定铺法生成函数，空铺法在每项中都计 1。

**恒等项。**由第 4 节，$D(x)=(1-x)/(1-4x+x^2)$。

**上下反射。**$W=h(W)$ 当且仅当每个字母由 $\sigma$ 固定。唯一固定字母是 $C$，所以恰好是 $C^\ell$，$\ell\ge0$，得到

$$H(x)=\frac1{1-x}.$$

**左右反射。**$W=v(W)$ 当且仅当它是回文。若字长为偶数，唯一写作 $U\operatorname{rev}(U)$；若为奇数，唯一写作 $Ub\operatorname{rev}(U)$，其中 $b$ 为任意基本块。两侧的总半长度是 $U$ 的半长度的两倍，所以 $U$ 的生成函数是 $D(x^2)$，不是 $D(x)^2$。故

$$V(x)=(1+F(x))D(x^2)=\frac{1+3x+x^2-x^3}{1-4x^2+x^4}.$$

**半周旋转。**$W=\rho(W)$ 当且仅当偶数字长时唯一写作 $U\sigma(\operatorname{rev}(U))$，或奇数字长时唯一写作 $Ub\sigma(\operatorname{rev}(U))$ 且 $b=\sigma(b)$。中心字母只能是 $C$，于是

$$R(x)=(1+x)D(x^2)=\frac{1+x-x^2-x^3}{1-4x^2+x^4}.$$

以上分类互斥且可逆，因而没有把仅满足必要条件的字计入，也没有遗漏对称铺法。是否有砖跨越几何中线已经包含在中心基本块中，不要求中线本身为断口。

## 7. Burnside 合并（L006）

固定 $n$ 后，铺法集合有限。数集合 $\{(g,T):g\in G,\ T\in\mathcal T_n,\ gT=T\}$ 得

$$\sum_{g\in G}|\operatorname{Fix}(g)|=\sum_{T\in\mathcal T_n}|\operatorname{Stab}(T)|.$$

每个轨道 $O$ 对右侧贡献为 $|O|\cdot|G|/|O|=4$，由此得到 $a(n)=(d_n+h_n+v_n+r_n)/4$。这个论证不要求群作用忠实，故也覆盖 $n=0,1$。

令 $P=1-4x+x^2$、$Q=1-4x^2+x^4$，逐项求和给出

$$A(x)=\frac14\left[\frac{1-x}{P}+\frac1{1-x}+\frac{2(1+2x-x^3)}{Q}\right].$$

通分后的分子是

$$\frac{(1-x)^2Q+PQ+2(1+2x-x^3)(1-x)P}{4}=1-3x-4x^2+10x^3-4x^5+x^6.$$

所以

$$A(x)=\frac{1-3x-4x^2+10x^3-4x^5+x^6}{(1-x)(1-4x+x^2)(1-4x^2+x^4)},$$

分子分母同乘 $-1$ 即第 1 节的原目标。原题的生成函数推导至此闭合。

## 8. 递推、初值与原题核对

分母展开为

$$1-5x+x^2+19x^3-19x^4-x^5+5x^6-x^7.$$

分子次数为 6，所以比较 $x^n$ 系数，对每个 $n\ge7$ 得到

$$a(n)=5a(n-1)-a(n-2)-19a(n-3)+19a(n-4)+a(n-5)-5a(n-6)+a(n-7).$$

较低次数的系数给出 $a(0),\ldots,a(6)=1,2,5,14,46,156,561$。这不是假设这些初值和递推后反推证明；它们是在一般组合推导完成后作为推论得到。
