# Public edition / 公开版说明

This is a curated research snapshot, not the complete private workspace.

Included: Chinese and English manuscript sources/PDFs; selected problem, approach, reference and lemma notes; both proposed proof routes; six final verification programs with their dependency layout; and sanitized historical numerical reports.

Excluded: personal author metadata beyond the English name, institutional and contact information, full archives, conversation and machine logs, local absolute paths, credentials, draft build caches, unrelated projects, superseded parser/report-format versions and unneeded images.

The Chinese manuscript PDF and all its TeX files are byte-identical to the retained source edition. The English public edition updates its abstract, status statements and reproduction notes to describe unfinished research, pending Lean verification and the curated public materials. Mathematical formulas are retained for review; retaining a formula is not certifying it.

Historical JSON reports have invocation, working-directory and platform fields removed. Their numerical fields are unchanged. Their source hashes identify the unchanged historical programs, not the modified JSON bytes. Each sanitized report is labelled explicitly. They are not represented as newly run experiments.

[PUBLICATION.json](PUBLICATION.json) records source-relative provenance, hashes and editorial treatments. It contains no absolute workstation path. Public code remains unchanged; commands should be run in a temporary working copy because some historical programs write metadata and reports.

[MANIFEST-SHA256.json](MANIFEST-SHA256.json) records the SHA-256 digest of every published file except the manifest itself, for checking this snapshot's integrity.

本公开版只包含适合复核的研究材料。中文论文 PDF 与 TeX 源码保持原样；英文论文增加未完成状态说明。数值报告去除本机调用信息和路径后公开，数学数据未改写。原始私人工作区中的所有版本仍在本地保留，筛选公开材料不等于删除历史记录。

No licence has been selected for this snapshot. Repository write permissions and the ability to read or fork a public repository are separate matters. The repository has no intended collaborator write access.
